# MED•VIH — Simulador educativo para estudiantes de Medicina

Sitio web interactivo en español para **aprendizaje y simulación** del algoritmo diagnóstico de VIH y el seguimiento de personas con VIH.

## Abrir el proyecto
La aplicación está contenida en [index.html](./index.html), y funciona en navegadores modernos sin servidor ni base de datos.

## Publicación con GitHub Pages
1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Configura **Branch: main** y **Folder: / (root)**.
4. Presiona **Save**. GitHub mostrará la URL cuando termine de publicarlo.

Dirección prevista tras habilitar Pages: https://danyqgzz.github.io/Med-VIH/

## Contenido
- Algoritmo de pruebas de cuarta generación, diferenciación VIH-1/VIH-2 y prueba de ácido nucleico.
- Evaluación inicial, seguimiento con carga viral y CD4, y calendario orientativo.
- Casos clínicos autocorregibles y resumen imprimible.
- Bibliografía médica consultable desde la página.

**Aviso:** exclusivamente educativo. No introducir datos identificables de pacientes: el sitio es público y no constituye expediente clínico ni reemplaza la consulta o los protocolos médicos vigentes. Revisión educativa: octubre de 2026.
